# mcp-sync v0.1.0

`mcp-sync` 0.1.0 is the first stable release of the local configuration CLI.
It defines MCP servers once in a strict canonical JSON file and reconciles them
into the global native configuration used by Claude Desktop, Cursor, Windsurf's
legacy Cascade integration, VS Code's default user profile, and Codex on macOS,
GNU/Linux, and Windows.

## Included

- Create-only import with deterministic conflict handling through `init`.
- Complete-definition canonical updates through `add` and structurally
  redacted inspection through `list`.
- Deterministic five-target `sync --dry-run` and recoverable transactional
  `sync`, preserving target-only and unowned native data.
- Explicit parser-validated `restore --dry-run` and `restore` for one retained
  adjacent backup generation.
- A five-second, 1-MiB-bounded local STDIO MCP initialize check through
  `test <name>`; no other command starts configured processes.
- Separate native ARM64 and x64 archives for macOS, GNU/Linux, and Windows.

## Release integrity

The macOS executables are Developer ID signed with hardened runtime and a
secure timestamp, then accepted by Apple's notarization service. The Windows
executables carry timestamped Public Trust Authenticode signatures. The
immutable GitHub Release includes one SHA-256 manifest, a target-specific SPDX
JSON SBOM for every archive, explicit GitHub build-provenance attestations, and
GitHub's release attestation.

Verify a downloaded artifact and the release itself with GitHub CLI:

```bash
gh attestation verify ./mcp-sync-v0.1.0-aarch64-apple-darwin.tar.gz \
  --repo EnjoyableWork/mcp-sync \
  --signer-workflow EnjoyableWork/mcp-sync/.github/workflows/release.yml \
  --source-ref refs/tags/v0.1.0
gh release verify v0.1.0 --repo EnjoyableWork/mcp-sync
```

## Scope boundaries

This release manages global configuration only. It does not discover or mutate
project-level Cursor, VS Code, or Codex files, named or remote VS Code profiles,
VS Code Insiders or extension-owned MCP stores, Codex credential stores, or
Windsurf's Devin Local configuration. Remote and otherwise unrepresentable
native entries are preserved and collision-protected rather than converted or
deleted. Current-client smoke evidence exists only for Claude Desktop and
Cursor on macOS; fixture and native built-binary coverage proves the other
implemented platform and client paths without making a current-client claim.
